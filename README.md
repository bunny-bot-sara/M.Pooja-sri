# 🤖 EduBot – Educational Assistant

> **Ask Anything. Learn Everything.**

EduBot is a simple and user-friendly educational assistant website designed to help students clear their doubts and learn difficult concepts in an easy-to-understand way.

It is designed for **school, diploma, and college students** and provides learning support across multiple subjects.

---

## 📌 Project Overview

Students often face difficulties understanding concepts, whether the doubt is difficult, simple, or even a small question they hesitate to ask.

**EduBot** provides a friendly learning environment where students can:

* Ask academic questions
* Get simple explanations
* Explore different subjects
* Learn useful study techniques
* Practice concepts
* Submit feedback

The current project is implemented as a **standalone web application** using HTML, CSS, and JavaScript.

---

## 🎯 Objectives

The main objectives of EduBot are:

1. To provide students with quick academic assistance.
2. To explain difficult concepts in simple language.
3. To support learning across multiple subjects.
4. To provide useful study tips and learning techniques.
5. To create a friendly and non-judgmental learning environment.
6. To make educational support easily accessible through a web browser.

## ⚙️ How to Run the Project

### Method 1 – Open Directly

1. Download or copy the project folder.
2. Locate `index.html`.
3. Double-click `index.html`.
4. The EduBot website will open in your default web browser.

**No Live Server is required.**

---

### Method 2 – Run Using Terminal

Open **PowerShell** or **Command Prompt** inside the project folder.

Run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

in your browser.

To stop the server:

```text
Ctrl + C
```
